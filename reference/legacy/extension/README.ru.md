# Проверка возможности интеграции с Meet

Это технический прототип, а не готовый переводчик. Секретов и подключения к
платным API здесь нет. VAC, VB-CABLE и Voicemeeter не используются.

1. В Chrome откройте `chrome://extensions` и включите «Режим разработчика».
2. Нажмите «Загрузить распакованное расширение» и выберите папку `extension`.
3. Обновите вкладку Meet и войдите в тестовый звонок со вторым участником.
4. Оставьте микрофон включённым, откройте расширение и нажмите «Открыть проверку на странице Meet».
5. Нажмите кнопку сигнала в появившейся панели непосредственно на странице Meet.
6. Собеседник должен услышать фразу «This is a translation audio test. One two three»; затем обычный микрофон
   должен восстановиться. Камера должна продолжать работать.

Для обновления уже установленного расширения нажмите кнопку перезагрузки его
карточки в `chrome://extensions`, затем обязательно обновите вкладку Meet.
После теста сохраните текст диагностической панели. Счётчики RTP показывают
отправку пакетов, но сами по себе не подтверждают, что собеседник слышит тестовую речь.

Сообщение о замене дорожки не доказывает доставку звука. Нужен ответ второго
участника. Если микрофон не восстановился, обновите страницу Meet.
После подтверждения этого этапа подключаются серверный перевод и захват вкладки.
