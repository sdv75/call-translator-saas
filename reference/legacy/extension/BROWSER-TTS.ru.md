# Проверка Piper в Chrome

Это отдельная проверка локальной озвучки. Перевод в Meet и сервер не изменены.

1. Обновите расширение кнопкой ↻ в `chrome://extensions`.
2. В окне расширения нажмите **«Проверить голос на этом компьютере»**.
3. Выберите русский или английский, нажмите **«Скачать голос»**. Каждый голос
   занимает примерно 63 МБ. Нужен доступ к Hugging Face. Файлы сохраняются
   локально в Chrome; незавершённая загрузка не считается готовым голосом.
4. Нажмите **«Создать озвучку»**, затем ▶ в аудиоплеере. Можно ввести свой текст.
5. Запустите **«Проверить оба языка»**: отдельно измеряется первый синтез,
   затем по пять коротких и длинных фраз на каждом языке. После прогона можно
   прослушать последнюю фразу; для проверки другой выберите язык и создайте её.
6. Скопируйте технический отчёт. Повторите полный прогон при открытом звонке
   Meet с камерой; сравните скорость и проверьте отсутствие помех в звонке.

Доля времени звука 0,2 означает: создание пяти секунд речи заняло одну секунду.
Критерий скорости: медиана менее 0,5 отдельно для каждого языка и длины фразы.
Качество произношения и плавность Meet проверяются прослушиванием.

Скачивание и подготовка модели измеряются отдельно от синтеза. Модели и
фонемизатор остаются в памяти worker до закрытия страницы или отмены операции.
Отмена завершает worker; следующий синтез снова будет холодным. «Удалить этот
голос» освобождает его локальный кеш. Без сети работает уже скачанная озвучка.

Текст и звук остаются в этой вкладке. Отчёт не содержит введённых фраз,
аудио, ключей или параметров подключения. В отчёте есть версия Chrome и
доступные браузеру сведения о числе логических процессоров и памяти устройства.
Это не замер расхода памяти: его можно посмотреть в диспетчере задач Chrome.

## Воспроизводимая сборка

Из `tools/browser-tts`: `npm ci`, затем `npm run build`. Версии зафиксированы
в `package-lock.json`. Готовые JS/WASM/data лежат в `extension/vendor/browser-tts`;
пользователю Node.js и npm не нужны. Зависимости и лицензии перечислены в
`vendor/browser-tts/THIRD-PARTY.md`.

Проверки: `node extension/test-tts-test.cjs`; из каталога сборки —
`npm run test:chrome` и `npm run test:chrome -- --full`. Полная проверка
скачивает модели во временный профиль, выполняет 22 синтеза и проверяет
повторное использование кеша без сети. Личный профиль Chrome и персональный
`connection.json` не используются. Артефакты проверки исключены из Git.
