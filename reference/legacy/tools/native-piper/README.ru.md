# Локальный Piper для Call Translator

Распакуйте весь архив и запустите `Install.cmd`. Установка выполняется для
текущего пользователя Windows, без аудиодрайверов и без отдельной установки
Python. Установщик найдёт распакованное расширение по пути, сохранённому при
сборке. Для другого пути передайте `-ExtensionPath`; для другого компьютера
запустите `install.ps1 -ExtensionId <ID расширения из chrome://extensions>`.

По умолчанию файлы находятся в `E:\Piper\versions` (путь можно изменить
параметром `-InstallRoot`), регистрация —
`HKCU\Software\Google\Chrome\NativeMessagingHosts\org.call_translator.piper`.
При обновлении создаётся новая папка; старые версии и предыдущая регистрация
сохраняются. Установщик сначала проверяет три голоса (ru/en/uk), затем меняет регистрацию.

В Chrome обновите расширение, обновите Meet и выберите «На компьютере (Piper)».
Первое включение может занять до минуты: загружаются три голоса. Далее процесс
остаётся в памяти до остановки перевода. Собеседнику устанавливать ничего
не нужно. Кнопка проверки Piper проверяет подключение отдельно от Meet.

Сервер по-прежнему выполняет распознавание и перевод; для локальной озвучки
нужна обновлённая серверная версия с поддержкой `tts: client`. Серверная
озвучка остаётся доступной. Автоматического перехода на неё при ошибке нет:
ошибка останавливает перевод и восстанавливает обычный микрофон.

Сборка из корня: `uv run --python 3.11 tools/native-piper/build.py`.
Предварительно скачайте голоса тестом `tools/benchmark-native-tts.py`.
Готовый пакет и архив находятся в игнорируемом `dist/native-piper/`.
Ключи, токены, Chrome-профили и connection.json в пакет не включаются.

Движок: Piper 1.8.0 (GPL-3.0-or-later), ONNX Runtime 1.31.1 (MIT), eSpeak NG
(GPL-3.0-or-later), NumPy (BSD). Исходники и инструкции Piper:
https://github.com/OHF-Voice/piper1-gpl/tree/v1.8.0
Голоса Ruslan, Joe и Ukrainian TTS (украинский) и их model cards:
https://huggingface.co/rhasspy/piper-voices
Зависимости и их лицензионные файлы включены сборщиком PyInstaller.
Для украинской модели текст перед синтезом приводится к нижнему регистру,
апострофы нормализуются, числа раскрываются словами (`num2words` 0.5.14,
LGPL-2.1). Исходный текст и перевод в стенограмме сохраняются без этих изменений.

Украинский голос скачивается командой `uv run --no-project --python 3.11 python
tools/native-piper/download-uk.py`; файлы проверяются по контрольным суммам
официального каталога. Поддержка украинского требует нового локального host:
после сборки запустите установщик пакета. Украинская озвучка доступна только
в режиме «На компьютере (Piper)». Сервер распознаёт и переводит речь; Piper
на сервере не запускается при старте службы и в локальном режиме.
