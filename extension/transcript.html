Папка для стенограмм

Папка загрузок Chrome

После завершения разговора стенограмма автоматически сохраняется отдельным HTML-файлом. По умолчанию — в папку загрузок Chrome. Файлы сохраняются при обновлении и удалении расширения. Если браузер закрылся во время разговора, файл будет сохранён при следующем запуске. Содержание не отправляется на сервер.
